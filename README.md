Proxy for Bittensor Staking - Ensuring 100% confidence and security for Subnet alpha token traders

# How to use


```bash
python3 scripts/gen_hash.py
```

Copy the result of gen_hash to ADMIN_HASH of app/core/config.py

Modify the appropriate WALLET_NAMES and DELEGATORS of app/core/config.py

Modify the port of run.sh file

```bash
./run.sh
```
